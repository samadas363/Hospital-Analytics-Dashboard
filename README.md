# 🏥 Hospital Analytics Dashboard

## 📌 Project Overview

An interactive Hospital Analytics Dashboard built using **Python, Pandas, Jupyter Notebook, and Microsoft Power BI** to analyze 5,000+ synthetic patient records and generate meaningful healthcare insights.

The project demonstrates the complete data analytics workflow from data cleaning and validation to exploratory analysis, KPI development, and interactive dashboard creation.

## 🎯 Project Objectives

- Analyze patient admissions and hospital activity
- Identify high-volume departments
- Analyze admission types and diagnoses
- Evaluate treatment costs and patient satisfaction
- Analyze patient length of stay
- Build an interactive dashboard for healthcare performance analysis

## 🧹 Data Preparation

Using Pandas, the dataset was prepared through:

- Duplicate detection and removal
- Missing-value handling
- Data type validation
- Length-of-stay validation
- Creation of age groups
- Creation of admission month and month number
- Weekday analysis
- Financial and departmental analysis

## 📊 Power BI Dashboard

The dashboard includes:

### Key Performance Indicators
- Total Patients
- Total Treatment Cost
- Average Treatment Cost
- Average Length of Stay

### Visual Analysis
- Monthly Patient Admissions
- Patients by Department
- Treatment Cost by Department
- Admission Type Distribution
- Top 5 Diagnoses by Patients
- Average Patient Satisfaction by Department

### 🔎 Interactive Filters

Users can filter the dashboard by:

- Department
- Hospital Branch
- Admission Type
- Gender

## 📈 Key Insights

The analysis helps identify differences in patient volume, treatment costs, admission patterns, diagnoses, length of stay, and patient satisfaction across hospital departments and branches.
